# VirtuStock Backend

VirtuStock is a stock market simulation platform that allows users to explore IPOs, trade stocks virtually, and track portfolio performance.

This repository contains the backend services built using Spring Boot.

---

## 🚀 Features

- JWT-based Authentication & Authorization
- IPO Listings & Application Workflow
- Portfolio Management
- Role-Based Access Control (Admin/User)
- Profit & Performance Analysis
- Scheduled Tasks for Data Processing
- Global Exception Handling

---

## 🛠 Tech Stack

- Java
- Spring Boot
- Spring Security
- JWT Authentication
- MySQL
- JPA / Hibernate
- RESTful APIs
- Maven
